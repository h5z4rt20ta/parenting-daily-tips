# 剖腹产恶露颜色

> 更新时间：2026-09-16 (UTC+8)

不管是剖腹产还是顺产，在产后都是会出现恶露的生理现象的，恶露是反映子宫恢复好坏的一个标志。对于破腹产的产妇来说，产后恶露的颜色会有什么变化的呢？下面妈妈网百科跟大家一起去了了解剖腹产恶露颜色是什么，以及恶露多久会排干净？

剖腹产后恶露颜色

一般来说，产后的恶露颜色是分为三个阶段和出现三种颜色的。不同颜色也是反馈了子宫的恢复情况，或者是身体有没有其他地方不好。

1、在产后1-4天内是出现的恶露是红色的

红色恶露又被称做为血腥恶露，因为产妇在产后第1天到第4天的时间内会排出一些分泌物，呈现是鲜红色的颜色，也因为恶露中含有比较多的血液，恶露的量也是比较多。次时的排出恶露的量一般可与平时月经相似，或者是稍多于月经的量，有时还带有血块。

2、在产后4-6天恶露变为淡红色

淡红色的恶露又被称作为浆液性恶露，这时候的恶露颜色呈现为淡红色，恶露中也含有少量的血液但是没有那么多了。而黏液以及较多的阴道分泌物，还有生长的细菌，都会在产后4-6天左右的时间排出。

3、最后一个阶段的恶露呈现的是白色的

白色恶露是在产后一周后排出的呈白色或淡黄色的恶露。其中含有白血球、蜕膜细胞、表皮细胞和细菌等成分，形状如白带，但是较平时的白带多些。

虽然每个产妇都会出现恶露的拍出，但每个人排出恶露的量是不同的，平均总量约在500到1000毫升。各产妇持续排露的时间也不同，正常的产妇一般需要2—4周，少数产妇可以持续1—2个月。

写在最后：产妇要重视和关注产后恶露的颜色变化的情况，对自己的身体情况能有比较好的把控！如果出现恶露不净或者是颜色不正常，就得到医院进行就诊。

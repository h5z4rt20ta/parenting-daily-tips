# 【喜报】河北省人民医院成为中国胸痛中心首批认证单位 47分钟内成功救治两例急性心肌梗死患者

> 更新时间：2026-09-16 (UTC+8)

**热烈祝贺**

2017年4月6日，在全国胸痛中心高峰论坛上，经中国胸痛中心认证工作委员会全体会议投票决定，**河北省人民医院胸痛中心成为2017年第一批中国胸痛中心认证的国家级胸痛中心。**

****

****

****

**此次胸痛中心的成功认证，将全面提升河北省人民医院胸痛诊治救治能力，同时也是积极响应中国国家卫生计生委提升急性心血管疾病医疗救治能力的新成果。**

这不，在3月29日，我们的胸痛中心发挥了作用，在47分钟内成功救治了两名急性心肌梗死的患者！

**第一名患者紧急救治**

2017年3月29日19 : 45，第一位患者因急性胸痛来到河北省人民医院急诊科就诊，经过了一系列详细的检查后，被诊断为“急性前壁心肌梗死”。

心内科总住院医生吴海波接到通知后，一键启动导管，经充分评估、与家属沟通后转运至心内导管室行急诊介入治疗。于20 : 32成功开通堵塞血管，入医院大门至堵塞血管开通时间仅用时47分钟。

**第二名患者介入准备**

与此同时，网路医院远程心电传输信息，第二位急性心肌梗死的患者正在转至我院的途中。胸痛中心即刻启动第二急诊介入小组，小组成员于 20 : 00 全部到达并完成手术准备。

患者于 20 : 20 到达医院大门，经再次评估后行急诊介入手术，20 : 55成功开通堵塞血管（入医院大门至堵塞血管开通时间）35分钟。

**截止2017年3月31日8 : 00，37小时内相继完成5例急性心肌梗死急诊手术。从进入医院大门直至堵塞血管开通时间最低为23分钟、平均32.6分钟，远远低于90分钟的国际救治标准。**

**这一成绩是河北省人民医院急性心肌梗死救治能力和水平的充分体现，亦是急诊科、心内科、导管室等科室同力合作、默契配合的结果。**

时间就是心肌，时间就是生命。当发现急性胸痛患者时，即刻拨打**河北省人民医院急救电话：85988120。**

胸痛中心将开启绿色无障碍通道，胸痛患者优先检查、优先治疗、先治疗后付费，争分夺秒，使胸痛患者及时得到诊疗与救治，从而降低急性心梗患者死亡率、致残率。
